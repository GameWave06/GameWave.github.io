THE WIFE SECRET WEBSITE — START HERE
====================================

Welcome! This is a ready-to-customize, mobile-friendly website for The Wife Secret.
You do NOT need to learn coding to publish it. First preview it, then replace the sample links and text.

WHAT'S INCLUDED
- index.html: the website content and links
- styles.css: dark-and-gold design
- script.js: mobile menu and small interactions
- assets/favicon.svg: browser tab icon

IMPORTANT BEFORE YOU PUBLISH
1. Search index.html for "https://itch.io/" and replace the two sample links with YOUR game's itch.io page URL and/or your real direct download URL.
2. Search for "Update soon" and replace it with the actual current public version.
3. The Patreon links currently point to https://www.patreon.com/GameWave957 . Verify that this is the correct public creator/page URL you want to show.
4. The page links to an older development post as an example. Replace it with the latest public post if desired.
5. The artwork panel is intentionally a CSS placeholder. To add your real cover, place a web-optimized image such as assets/cover.jpg in the assets folder. Then ask for help changing the artwork panel to display it.
6. Add other payment/support links only after you create and verify those accounts. Never put bank account numbers, private emails, passwords, or other private data in website code.
7. If your game contains adult content, follow the rules of the hosting platform and make the age notice/content warnings appropriate. A notice alone does not make every platform permit adult content.

PREVIEW ON YOUR COMPUTER
- Extract the ZIP file to a folder.
- Double-click index.html. It should open in your browser.
- If your browser blocks anything locally, the website is still static and can be published as described below.

PUBLISH FOR FREE WITH GITHUB PAGES (BEGINNER ROUTE)
1. Go to https://github.com/ and create a free account or sign in.
2. Create a NEW PUBLIC repository named exactly: your-github-username.github.io
   Example: if your username is tarunexample, repository name should be tarunexample.github.io.
3. On the new repository page, choose "Add file" > "Upload files".
4. Upload index.html, styles.css, script.js, README-FIRST.txt, and the assets folder (including favicon.svg). Upload the CONTENTS of the website folder, not the ZIP file itself.
5. Click "Commit changes".
6. In the repository, open Settings > Pages.
7. Under Build and deployment, choose "Deploy from a branch". Select branch "main" and folder "/ (root)", then save.
8. Wait a few minutes and visit https://your-github-username.github.io/ (replace with your actual username).
9. If the site does not appear, open the Actions tab and check whether the Pages deployment has completed.

If GitHub's buttons look different, use its current official Pages guide:
https://docs.github.com/pages/getting-started-with-github-pages/creating-a-github-pages-site

IMPORTANT PRIVACY / SECURITY
- This is a static public website. Anything in its files is visible to visitors.
- Never upload your Ren'Py source project, private game builds, passwords, API keys, private supporter data, or personal documents to the website repository.
- Direct download links should point only to builds you intend to make public. For large builds, use a game distribution/hosting service rather than putting the game ZIP in the website repository.
- Keep offline backups of the website and game files.
- GitHub Pages is suitable for a public information site, not a private membership system or payment processor.
